# user_settings

複数の事例で共通に参照する設定ファイルの置き場です（ppt-md-merger 本体リポジトリの `user_settings/` と同じ役割）。

各事例のレシピ（`cases/<事例>/src/*.yaml`）からは `../../../user_settings/...` で参照します。
本体リポジトリの `examples/<サンプル>/src/` と同じ深さなので、本体のサンプルをそのまま移しても相対パスが変わりません。

| ディレクトリ | 中身 |
|---|---|
| `pandoc/` | pandoc の `data-dir` として指定する defaults ファイルと CSS |

ここに置くのは「2つ以上の事例が使う」ものだけにしてください。1つの事例でしか使わない設定は、その事例の `src/` に置きます。
事例の zip を作るときは、その事例が参照している `user_settings/` 以下のファイルも同じ相対位置で zip に入れます。
